# 重点钱包：快速使用

1. 在“机会监控 → 监控设置”配置自己的 Robinhood HTTP RPC，可选填 WebSocket。钱包跟踪复用该配置，但不需要启动机会扫描。
2. 打开“重点钱包 → 编辑清单 / 参数”，每行填写公开地址。也可按以下格式填写：

   `公开地址 | 自定标签 | 分类 | 关联组 | 重点`

   最后一项可填“重点”或“观察”。只填地址时默认为观察。不要填私钥。
3. 分类用于搜索。你已确认属于同一控制方的地址，可设为同一个关联组；多人参与信号中合并计数。没有分组不代表已经核实相互独立。
4. 保存后点击“启动钱包监控”。默认首次回看 300 个区块、等待 2 个区块，每 4 秒通过 HTTP 补查。
5. 重点钱包主动 mint 或匹配买卖时提醒。观察钱包参与默认的“5 分钟内至少 3 组参与同一合约”条件时提醒。单个观察钱包的活动仍显示在列表。
6. 点击 NFT 名称查看 OpenSea；点击“查询地板 / 成交”使用自己的 OpenSea API Key 查询行情。地板是卖方挂单，不是已成交价格。
7. “添加 mint 项目”只打开草稿。需要自行核对合约、价格、预算并完成原有启动步骤。
8. 开启声音后保持页面打开。软件退出或电脑休眠会中断监控；启动前的历史活动不触发实时声音。

## 为什么没有提醒？

- 查看检查时间及扫描区块是否持续推进，是否显示错误。
- “已保留 0 条活动”表示已扫描范围内暂未识别到活动，不代表钱包在所有链上都没有动作。
- 有活动但无提醒：可能是观察钱包未达到多人门槛、普通转账或历史补查。
- 可切换“全部活动（含转账）”，并清除搜索和合约筛选。

## 数据边界

仅支持 Robinhood 4663 标准 ERC-721 / ERC-1155。主动 mint 要求交易发送者与 NFT 接收者相同；代付 mint 与普通转入分开显示。买卖只识别匹配的 Seaport 成交，不推断其他市场的买卖。

整笔交易 value 和 gas 不等于单件 NFT 成本。最多保留 2,000 条活动，页面显示最近 500 条；修改清单会清空活动缓存并重新补查。清单默认空白，标签、来源和盈利能力由使用者自行核实。

后台使用配置的 RPC，行情查询使用 OpenSea 接口额度，不调用 AI。新发布包不含用户配置或监控地址；不要转发使用过的文件夹。
