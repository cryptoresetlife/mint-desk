# Mint Desk · 自动 mint 软件

## V1.0 多币种上架修复

- 上架窗口先识别系列的 OpenSea 报价币种，核对链上代币地址、符号和小数位，再开放售价输入。支持原生 ETH 与系列指定的标准 ERC-20 报价币种，如 USDG、USDC、WETH。不是任意切换币种。
- USDG 按 6 位小数计价；手续费、预计到账和订单均使用相同报价币种，授权 gas 另付 ETH。无需为了卖出 NFT 而授权或预存报价代币。
- 售价不会沿用旧版 ETH 输入或自动换算；例如填 20 USDG 就是挂 20 USDG，不是 20 ETH。
- 不同报价币种的 NFT 请分批上架。平台币种、代币精度或费用变化时停止并重新预检，避免误价。
- 原生币与标准 ERC-20 的固定售价已支持；特殊交易区域、自定义订单、拍卖、改价及撤单仍需到 OpenSea 操作。

## V1.0 我的 NFT 与批量上架

1. 在 **钱包管理** 导入自己的钱包，在 **监控设置 / API Key** 填写自己的 OpenSea API Key；无需启动监控也可查询持仓。
2. 打开 **我的 NFT**，选择钱包和网络，点击 **刷新持仓与上架状态**。支持 Robinhood / Ethereum；可以勾选“只看本软件打到的”。持仓来自 OpenSea 索引，并以本文件夹保存的成功 mint 记录补充，可能有索引延迟。
3. 点击 NFT 名称前往 OpenSea，或点击 **查询地板 / 成交价** 查看参考行情。地板挂单不是实际成交收入。
4. 勾选同一钱包的 1–20 项 NFT，点击 **批量上架**，自行填写统一售价、有效期、每次授权 gas 上限。每项出售 1 个；不同价格请分批设置。
5. 点击 **预览上架费用**，核对 NFT、平台和创作者费用、扣费后预计到账、授权范围与 gas 预算。修改售价或期限后必须重新预览。
6. 勾选授权后点击 **确认并一键上架**，软件才会执行必要的链上 NFT 授权并签署、提交 OpenSea 订单。在 **运行任务** 查看进度，完成后返回 **我的 NFT** 刷新上架状态。订单成交后才有卖出收入。

- 支持标准 ERC-721 / ERC-1155 的固定价格上架，使用系列指定的原生 ETH 或经链上核验的 ERC-20 报价币种；特殊交易区域暂不支持。
- ERC-721 优先授权单个 NFT；ERC-1155 若需要授权，会授权指定 OpenSea 通道操作该系列全部 NFT。授权不随订单到期自动撤销。已有有效授权时不新增授权交易。
- 上架批次与 mint 共用同钱包发送协调，不会占用同一交易序号。不同钱包可分别建立任务；同钱包的发送需要等待，临近抢 mint 时请避免同时启动上架批次。
- 本批最高 gas 预算按“所选项数 × 每次授权 gas 上限”预留；上限不是固定扣款。每项预计到账未减实际授权 gas，也不保证有人购买。
- 已有有效挂单或未过期的本地提交记录会阻止重复上架。提交结果不明时不自动重试；请到 OpenSea 核实。撤单、改价目前在 OpenSea 操作；本地未过期记录会保守阻止再次提交，直至到期。
- 订单公开元数据保存在 `data/listings`，授权交易记录保存在 `data/attempts`；不保存订单签名或私钥。分享原始 ZIP，不分享用过的文件夹。
- 更新时先结束需要停止的任务并退出软件，再打开新版、重新导入钱包。新解压的分享包是空配置，不包含你的历史记录；原文件夹的本机记录请自行保留。

## V1.0 多项目协调

- 每个项目分别选择钱包、检查费用并授权启动；无需先停止另一个项目。所有项目可同时等待和提前准备。
- 不同钱包可以并行发送。同一个钱包在同一条链上每次只发送一笔，前一笔入块后，再刷新交易序号、余额并模拟下一笔。先准备就绪并取得发送机会的项目先发送。
- 前一笔超时、停止或结果不明时，后续项目等待链上回执，不复用序号、不自动替换交易；重启后仍检查已保存的交易记录。
- 同一个钱包可以用于不同系列；同系列重复任务仍会拦截。停止一个项目不会停止其他项目。
- 预检会显示其他任务预留的预算。启动时余额必须覆盖该钱包所有任务的最高授权之和（数量 × mint 单价上限 + gas 上限），避免多个项目重复使用同一份余额。上限不是实际扣款。
- 软件图标、托盘图标和网页图标统一为绿色 M_ 终端；显示版本保持 V1.0。
- 更新需退出并重新打开软件，随后重新导入钱包、检查并启动需要的项目；运行中的任务不会自动迁移到新版。

## V1.0 机会雷达

- 利润达标、即将开售（1 小时内）、早期升温、原始发现分开查看；没有成交依据时标记收益未知。
- 早期升温：指定 SeaDrop 的公售 mint，连续采样 5 分钟；5 分钟至少 8 个接收地址，1 分钟至少 3 个地址及 3 笔交易，交易速度至少为前 4 分钟均速的 2 倍，单接收地址和单付款人数量占比都不超过 50%。这些是发现规则，不是盈利预测。
- 采样按区块时间计算，重复事件去重，回查历史不当作实时爆发；断线、遗漏风险或重组后重新收集。
- 提醒默认只包含利润达标，早期升温及临近开售提醒需单独勾选。不会自动添加钱包或启动 mint。
- 临近开售及参与升温的已识别系列优先加入最多 50 个 OpenSea 行情订阅，并优先进入下一轮核验。
- 非标准合约入口来自已扫描的 OpenSea 系列，仅供查看，不能自动 mint；不是全链所有合约扫描。官方来源、共同资金来源及转售限制仍需自行核验。


## v1.1 内置机会监控

左侧 **机会监控 → 监控设置 / API Key**，用户必须填写自己的 OpenSea API Key。去 https://opensea.io/settings/developer 创建普通 API Key 即可。默认空白；不读取旧版扫描器、分享者或其他软件中的 Key。验证后保存在本软件 `monitor/data/opensea-key.local.json`，界面和日志不回显 Key。可留空沿用、更换、删除本机 Key。

点击 **启动监控**，程序在本机自动扫描，不创建 Codex 自动任务、不使用 AI 额度，但会使用网络和所填接口的配额。停止监控会终止扫描和连接，不停止 mint 任务。软件重新启动后要手动再次启动监控。

- Robinhood：免费和付费公售均包含，不设固定 gas 筛选上限；默认保守估算净利润 ≥ 总成本 × 2。
- 总成本包含 mint 价格、mint gas、出售 gas 和估算平台／创作者费用。依据成交证据折价估值，不把高地板挂单当成实际卖出收入。样本不足、费用未知或估算失败时不列为优先复核。
- 默认每轮结束后 300 秒启动下一轮，设置可修改。每轮最多核验 80 个系列，公开页面发现、历史发现和自选列表合并，非全站全量覆盖；限流时退避，不绕过限制。
- 同时读取 SeaDrop 链上事件、公售状态，首次回查约 24 小时；已识别项目可接收 OpenSea 行情流，最多订阅 50 个系列，其他系列靠定时扫描。断线可能遗漏事件。
- HTTP RPC 默认官方公共接口。可选填自己的 HTTP／WS 节点；不会带上作者的局域网地址或 Alchemy Key。
- **加入 mint 项目**只打开草稿；价格、钱包资格、数量和预算仍须在 mint 页重新检查并由你授权。监控 worker 无钱包私钥，不签名、不广播。
- 声音提醒需点击开启，并保持软件页面打开；浏览器后台限制或系统休眠可能影响提醒。

`monitor/data` 中的 Key、RPC 设置与缓存属于本机数据；给朋友只发送原始 v1.1 ZIP。无需登录或访问分享者的 panel.authalpha.com。

解压整个文件夹，双击 **Mint Desk.exe**。不需要安装 Node，不需要手动编辑记事本。备用入口 START.cmd。

## 使用步骤

1. **我的项目 → 添加 NFT**。输入 OpenSea 系列链接点“识别”，或直接填写 NFT 合约地址。选择 Robinhood / Ethereum，粘贴自己的 RPC。
2. 设置每钱包数量、单个 mint 价格上限、每钱包单笔 gas 总费用上限。免费项目价格填 0；gas 支持 0.001、0.01、0.1 等正数，没有旧版 0.01 硬上限。ETH 与 Gwei 不同，表单全部按 ETH 计。
3. **钱包管理**粘贴私钥，多个私钥以换行或空格分隔。输入隐藏，仅保存在本次软件内存。可导入最多 100 个钱包。
4. 回到项目，点击**选择钱包并运行**。输入要用的钱包数量，或逐个勾选；点击**检查钱包与费用**。
5. 核对网络、合约、单价、开始时间和整批预算。勾选真实交易授权，点击**开始自动 mint**。已经开售时会尽快预检并尝试交易；未开售时自动等待。
6. 在**运行任务**查看每钱包进度、gas 和交易哈希。软件停止、交易失败或回应不明，都不会自动用新 nonce 重发。

## 支持范围

自动 mint 支持 Robinhood 4663 与 Ethereum 1 上核验过的 SeaDrop V1 合约的 **Public 公开阶段**，免费或原生 ETH 付费。mint 到付款钱包本身，调用 mintPublic；不包含 ERC-20 授权、主动转账或 reveal。独立的“我的 NFT”页面支持经用户确认的 NFT 授权与 OpenSea 上架，具体范围见上方说明。

不是所有 OpenSea NFT 都能直接 mint。白名单证明、持有资格、签名销售、自定义合约和 ERC-20 支付需单独适配；不能把币种或合约方法猜成 ETH 公售。链接识别失败可填地址；保存项目时仍会查链与合约。

mint 项目名称与公开合约读数不代表项目安全背书。公售前其他阶段可能耗尽库存。

## 速度与预算

- 继承旧版提前准备思路：开售前 60 秒尝试时间预演并在内存签名；RPC 不支持预演时，开售后转标准模拟。不得跳过失败的模拟。
- 临近开售按 100 毫秒间隔加请求耗时检查；每钱包分别进行真实 pending 调用，最多 20 路提交。多个钱包的回执独立等待。
- Robinhood 将同一笔签名同时交给所选 RPC 与官方排序器；交易哈希和 nonce 相同，不是买两次。Ethereum 只使用所选 RPC。
- 价格、nonce、余额和参数变化后重新检查。gas 估算留出用量 25%、单价 20% 余量，签名总 gas 上限不能超过设置金额。签名余额检查包含 mint 金额。
- 总授权上限 = 钱包数 ×（每钱包数量 × 单价上限 + 每钱包 gas 上限）。预算上限不是固定扣款，不代表一定有足够余额，也不保证抢到。
- 原生币 mint 的单价精确取链上配置；不发送上限金额作为额外付款。

## 数据与退出

钱包私钥不会写到文件、日志或浏览器存储，不发送到 RPC；仅由页面传到本机 127.0.0.1 服务。程序运行内存和本机系统应由你自己控制。JavaScript 内存不提供硬件级安全擦除保证。

RPC 地址（可能含 API Key）和项目配置保存在 `data/projects.local.json`。交易尝试保存在 `data/attempts`，只有地址、交易哈希等公开记录。广播前先落盘锁定，防止超时或重启导致重复购买。不要删除尝试记录来重跑；需要先核实链上结果。本软件不能感知旧版 bot 文件夹里的本地记录，请勿让旧版和新版同时操作同一钱包。

关闭浏览器窗口不会停止后台任务。需要退出时点左下角 **停止任务并退出软件**。已广播交易无法撤销。电脑需要保持开机、不休眠；睡眠恢复后会重新核对区块时间。

重新启动要重新输入私钥、检查并启动任务，不会擅自恢复真实 mint。

给朋友只发送原始 ZIP，不能发送已经用过、含 `data` 的文件夹。发行包不含私钥、RPC Key 或个人交易记录。

## 验证范围

包含预算、链匹配、签名目标、重复发送、并发、停止和本地接口防跨站测试；用只读链上检查验证接口。交付时没有用真实钱包广播任何测试交易。首次使用应先用 1 个钱包、小预算核对行为。

合约依据：[OpenSea SeaDrop 源码](https://github.com/ProjectOpenSea/seadrop/blob/main/src/SeaDrop.sol)。


## v1.2 项目行情

我的项目卡片可点击“查询行情”，使用你在监控设置中保存的 OpenSea API Key，按网络和 NFT 合约识别系列，显示地板挂单价、最近 24 小时的单件二级成交样本、成交时间和交易链接，并提供“查看 OpenSea”。保留 ETH、USDG 等原始币种，不把 USDG 误写成 ETH。没有返回成交样本时显示未找到，不代表成交价为零或从未有过成交。报价和成交样本可能失真；不据此自动改变 mint 预算或开始 mint。

行情按按钮查询，60 秒内复用缓存；无需启动监控。监控已有数据可作为带时间的历史参考。点击“选择钱包 / 预检”不会发交易，必须完成预检、勾选授权并点击“开始自动 mint”。

从 v1.1 更新：退出软件后重新打开以加载新的行情接口。私钥只在进程内存，退出后需要重新导入；不要在有 mint 任务运行时更新。

行情接口文档：https://docs.opensea.io/reference/list_events_by_collection


## v1.2.1 分享版与启动隔离

原始 ZIP 不包含用户项目、RPC 配置、OpenSea Key、钱包、交易历史或扫描缓存。首次解压启动应为零项目、零钱包、Key 未配置；内置公共 RPC 是默认服务地址。只分享原始 ZIP，不转发使用后产生配置的文件夹。

v1.2.1 启动器会核对后台所属文件夹。另一文件夹的 Mint Desk 或旧版后台占用 8792 时，会提示冲突并停止打开，不会把那份程序的钱包误显示为新安装包的钱包。START.cmd 也通过同一启动器检查。请在原软件里自行停止任务并退出，等待约 8 秒，再打开新副本；单纯关闭网页不会停止旧后台。


## v1.2.2 启动修复

修复 Windows 空闲端口检查超过 800 毫秒时误报后台冲突。现在先查询系统监听端口，再直连本机健康接口；检查超时会单独提示未完成核实，不再误报另一份后台。仍核对后台所属文件夹，保留防误连保护。


## v1.2.3 默认机会筛选与提醒

链上候选默认只显示通过现有保守成交估值和净利润倍数条件的项目。还要求 15 分钟内行情、至少 3 笔不同交易和 2 个买家的成交依据、成功的 gas 模拟；最新链上库存或状态不允许 mint 时不列入。原始发现继续读取，可在“显示范围”切换查看，不因为项目名称含 Test 就直接认定诈骗或永久删除。

普通活动和取消挂单不再刷屏或响铃；开启声音后，只对新进入利润筛选的项目和符合筛选项目的开售提醒响铃。零个合格结果是正常情况，不保证覆盖所有项目或保证收益。此次前端更新刷新页面生效，无需重启后台或重新输入钱包。


## V1.0 链上 mint 成本

1. 更新后彻底退出旧后台，再打开 Mint Desk.exe 并重新导入钱包。
2. 我的 NFT → 刷新持仓与上架状态：自动查询最多 10 项缺失的历史 mint 成本。
3. NFT 卡片和上架窗口显示 mint 实付、每件分摊的实际 gas 和合计。点击交易哈希可核对回执。
4. 没查到时，点击“填写 / 修改成本”→“从链上读取 mint 成本”；可选填 mint 交易哈希。买入、转入和其他不支持的协议需手填。
5. 手填成本优先保留；清除手填后恢复核验的链上记录。刷新读取的是历史 mint 支出，不保证覆盖索引遗漏、后续买回或链外费用。发现转出或历史不完整时不据此计算当前盈亏。

自动查询仅调用 OpenSea 官方只读接口和所配置 RPC，不签名、不广播、不产生 gas；会消耗所用接口的查询额度。只支持已核验的 SeaDrop Public ERC-721 直接付款 mint；分享包不带任何用户成本记录。

## NFT 图片与系列封面

在监控设置填写自己的 OpenSea API Key。“我的 NFT”和重点钱包活动显示单张 NFT 图片；我的项目、机会雷达、链上候选与提醒显示系列封面。点击已取得链接的图片可打开 OpenSea。

图片按需加载，向下滚动才查询新卡片；切换筛选不会重复查询已缓存的图片。未收录、未揭示或缺图时显示占位提示。刷新列表可稍后重试，缺失结果短暂缓存一分钟。图片不代表项目质量或盈利能力。
