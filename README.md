# Mint Desk V1.0

Windows 本地 NFT 监控与自动 mint 工具，支持多项目同时等待、提前准备和同钱包协调发送。

- **机会监控**：Robinhood 链，查看利润筛选、即将开售、早期升温和原始发现。
- **自动 mint**：Robinhood / Ethereum 上支持的 SeaDrop Public 公开阶段，包含免费和原生 ETH 付费项目。
- **多钱包、多项目**：最多导入 100 个钱包，每个项目单独设置数量和预算。

[下载 Windows V1.0 完整包](https://github.com/cryptoresetlife/mint-desk/releases/download/v1.0/Mint-Desk-Windows-V1.0-Multi-Share.zip) · [版本发布页](https://github.com/cryptoresetlife/mint-desk/releases/latest)

## 1. 安装与启动

1. 下载发布的 ZIP 安装包。
2. **完整解压**到一个文件夹，不要直接在压缩包内运行。
3. 双击 **Mint Desk.exe**，软件会打开本机操作页面。

已包含运行环境，无需另外安装 Node.js。备用入口为 `START.cmd`。

## 2. 开启监控（可选）

1. 打开 **机会监控 → 监控设置 / API Key**。
2. 填写自己的 OpenSea API Key，可通过页面中的开发者设置链接创建。
3. 填写 Robinhood RPC，或沿用默认公共接口；WebSocket RPC 可不填。
4. 保存设置，点击 **启动监控**。

点击项目名称可查看对应 OpenSea 页面；点击 **加入 mint 项目**打开项目草稿。原始发现和早期升温可能没有成交或利润依据，需自行核实。

监控在本机运行，会使用网络及接口配额。**发现项目不会自动购买**，仍需完成下面的运行步骤。

## 3. 添加 NFT 项目

打开 **我的项目 → 添加 NFT**，填写以下内容：

| 设置 | 怎么填 |
| --- | --- |
| OpenSea 链接 | 粘贴系列链接后点击“识别”；也可直接填写 NFT 合约地址 |
| 网络 | 选择项目所在链，RPC 必须对应这条链 |
| NFT 合约地址 | 填项目的 NFT 合约地址，不是钱包地址 |
| 每个钱包 mint 数量 | 每个选中钱包要 mint 的数量，需符合项目限额 |
| 单个 NFT 价格上限 | 单位 ETH；填 `0` 表示只接受免费 mint |
| 每钱包单笔 gas 上限 | 单位 ETH，例如 `0.001`、`0.01`、`0.1`；是总费用上限，不是 Gwei |

点击 **检查合约并保存**。保存项目不会发送交易；预算上限也不是固定扣款金额。

## 4. 导入钱包

打开 **钱包管理**，输入私钥并点击 **导入钱包**。多个私钥可用换行或空格分隔。

- 私钥仅保存在本次软件内存中，退出后需要重新导入。
- 钱包需要有目标链上的 ETH，用于 mint 付款和 gas；免费 mint 也可能消耗 gas。
- 私钥只在本机软件内填写，不要上传到 GitHub、Issue 或截图中。

## 5. 启动自动 mint

1. 在 **我的项目**中点击 **选择钱包并运行**。
2. 选择钱包数量，或逐个勾选钱包。
3. 点击 **检查钱包与费用**，核对项目、网络、数量和预算。
4. 勾选真实交易授权，点击 **开始自动 mint**。
5. 到 **运行任务**查看等待、准备、广播和回执状态。

**点击“开始自动 mint”后才会自动执行。** 未开售时等待并尝试提前准备；已开售时会尽快检查并尝试发送。能否成功取决于资格、库存、余额、网络和链上执行结果。

项目卡片中的 **查询行情 / 查看 OpenSea**可用于核对地板挂单与成交记录。地板挂单价不等于实际卖出价。

## 6. 多项目同时运行

对每个项目分别完成“选择钱包 → 检查费用 → 授权启动”，无需停止前一个项目。

- **不同钱包**：可以并行发送。
- **同钱包、同一条链**：多个项目同时等待；前一笔入块后，重新检查交易序号、余额和模拟结果，再发送下一笔。
- **前一笔结果不明**：后续发送等待回执，不自动替换前一笔。
- **预算**：余额必须覆盖该钱包所有任务的最高授权预算之和；预检会显示其他任务预留的金额。
- **停止**：可单独停止一个项目，不影响其他项目；已广播的交易无法撤回。

同一钱包、同一系列的重复任务会被拦截。软件不会因为失败或超时而自动重发购买。

## 7. 退出、更新与分享

- 保持电脑开机、不休眠。仅关闭网页不会停止后台任务。
- 完全退出请点击左下角 **停止任务并退出软件**。
- 更新前先处理好正在运行的任务，再退出并打开新版；钱包和任务需要重新导入、检查及启动。
- 给朋友只发送原始 ZIP。使用后的文件夹可能包含 RPC Key、OpenSea API Key 和交易记录，**不要直接上传整个文件夹**。

## 常见问题

**添加项目失败？** 先确认网络、RPC 和 NFT 合约地址一致。本版仅支持指定 SeaDrop 公开阶段；白名单、签名资格、ERC-20 付款和自定义 mint 合约暂不支持。

**没有“值得打”的结果？** 可能没有项目满足筛选条件，或成交、报价等数据不足。原始发现可以查看，但不代表符合利润条件。

**提示后台冲突？** 另一份软件可能仍在运行。回到原软件点击“停止任务并退出软件”，等待退出后再打开新副本。

**交易显示结果不明？** 通过交易哈希核实链上状态；不要删除交易记录来强行重复运行。

---

监控结果仅供筛选与核实，不保证盈利或抢到 NFT。真实交易失败也可能消耗 gas。
